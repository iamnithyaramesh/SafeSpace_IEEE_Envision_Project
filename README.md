# SafeSpace

**SafeSpace** is an educational mobile application designed for children and young adults aged 6 to 15 years. It offers a safe, engaging platform that provides age-appropriate sex education, soft skills development, and adolescence education. The app seeks to empower young individuals with the knowledge and confidence needed to navigate their personal and social growth responsibly.

---

## Problem Statement

In many regions, children and teenagers lack access to structured and safe educational content regarding personal development, emotional health, and sexuality. This absence creates a gap in their understanding, self-esteem, and ability to make informed decisions.

**SafeSpace** addresses this challenge by:

* Delivering child-friendly educational content
* Promoting safe, inclusive, and respectful development
* Teaching essential life skills, including empathy and communication
* Providing an anonymous and judgment-free space for learning

---

## Features

* Modular, age-specific curriculum with progression paths
* Topics covering:

  * Consent and personal boundaries
  * Emotional intelligence and communication
  * Puberty and body awareness
  * Conflict resolution and self-esteem
* Game-based learning components using the Flame engine
* Firebase integration for secure data handling and user management
* Template-based UI design supporting future expansions

## Setup and Deployment

To clone and run the project locally:

```bash
git clone https://github.com/iamnithyaramesh/SafeSpace_IEEE_Envision_Project.git
cd SafeSpace_IEEE_Envision_Project/flutter_game_template
flutter pub get
flutter run
```

Prerequisites:

* Flutter SDK installed and configured
* Firebase project with Firestore and Auth enabled
* Emulator or physical Android device connected
